## 事故三（2026-10-15）：测试夹具用映射网络盘造"不可用" ⇒ 存在性探测 9.3s+ ⇒ 全链 G3 假红

- **现象**：全链 `npm run verify` 的 G3 只红一条 —— `tests/dsh-ask.test.js`「运行包不可用 ⇒ 响亮抛错」；
  单跑该文件 26/26 全绿（那一条 21.0s 贴 30s 上限过），链内高载下超 30s 被判红。
- **根因**：夹具用 `X:\nope` 造"不可用"，而 X: 是映射网络盘（\\SZ-13049822-01\D）且不可达 ⇒
  `fs.existsSync('X:\nope')` 实测 9303ms/次（复测 21067ms，随网络状态波动；对照 C: 0ms、Y: 2ms），
  `resolveRuntime` 的多次存在性探测在链内被放大 ⇒ 超时。**环境红，非产品回归**
  （src/dsh-ask.js / src/dsh-package.js 零工作树改动）。
- **判据**：单跑 `tests/dsh-ask.test.js` 26/26 绿 + 链内该用例超 30s；存在性探测耗时两档：
  不可达映射盘 9.3s+（且会随网络状态涨到 21s），本地不存在路径 <1ms。
- **修法**：夹具换成快速失败的本地不存在路径（`C:\__definitely_not_exist_dsh_ask_fixture__\nope` 与 `…nope2`；
  Z: 也已被映射 ⇒ 同样不许用），测试意图不变（仍是"运行包不可用 ⇒ 响亮抛错"）；
  夹具处加一行注释：别用映射网络盘做"不可用"夹具。
- **遗留**：产品侧 `resolveRuntime` 对慢映射盘（不可达网络路径）的健壮性（存在性探测的超时/缓存/跳过）＝待办，
  本次未改产品代码。

## 派生禁令（**必须遵守**）

1. **不移动目录**。改名只改 `SKILL.md` frontmatter 与 `package.json` 的 `name` 字段，
   禁止 `robocopy /MOVE`、禁止移动 `.user_skills` 内的任何目录。
2. **不用 PowerShell 读写 UTF-8 文档**。`Get-Content` / `Set-Content` / `Out-File`
   在 PS 5.1 下默认 GBK，会损坏中文文件；一律用编辑器 / Write / Edit 工具。
   文档必须是 **UTF-8 无 BOM**。
3. **不做批量写盘**。禁止批量 `writeFileSync` 脚本、禁止一次性重写大量文件
   （企业安全软件会把这类行为判定为可疑操作并清理目录）。
4. **大改前先导出备份**。涉及大量节点增删前先 `export-json` 一份到**工程外**目录
   （单文件含全部图片，可整体回滚）。
5. **写盘必须原子**。`src/data-store.js` 的 `writeFileAtomic`（临时文件 + fsync + rename）
   是唯一写盘出口；新增写盘路径必须复用它，避免中断产生半截文件。
6. **整文件改写只用"精确串替换"，且必须检查锚点唯一性**（2026-10-22 补录）。
   用 `split(锚点).join(新文)` 做替换等于**全局替换**：锚点在同一文件里出现两次，就会把中间那一段一起吃掉 ——
   文件被**静默切断**，语法还可能照样合法（`node --check` 也可能绿），只有行为判据才发现。
   **真实事故**：锚点 `];` 在 `addTopic` 的 `topics` 数组后也出现 ⇒ 整个冒烟断言文件被切断。
   **正确做法**：只替换**第一个**匹配（`indexOf` + 切片），并且**找不到锚点就 `exit 1`**（不许"静默成功"）；
   已经改过的要能识别（幂等回执）。

   > ⚠️ **本条为什么迟到了三年**：它被**识别过至少三次**（最早 2026-09-25 的
   > `.review/20260925-scripts草稿清理/_patch.js:1-3`，然后 `.review/20261020-调研/18-退役两步留痕.md:85`
   > 与 `:104-109` 连**可直接粘贴的原文**都写好了），而 `INCIDENTS.md` 一直只有 5 条。
   > ⇒ **根因不是"没人发现"，是"发现之后没有一条路径能把它落进去"** ——
   > 「退役两步」的第一步（抢救"为什么"）**没有任何门禁看着**，所以它永远可以留给下一批。
   > ⇒ 这条留在这里，同时也是那条机制的**现场证据**：`docs-for-ai` `D5` 的"顺序不能反"需要有人认领。
   > ⚠️ **如实**：该事故**只有草稿自述，未独立取证**（没翻 git 历史找那次切断）。
   > 保留它的理由是**损害方向与本段其余 5 条同类**（静默损坏、不可见），且**代价只有一段话**。
