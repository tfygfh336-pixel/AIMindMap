### 深度审查与修复（2026-09-15，事故后全面体检）

用户要求对恢复重建后的工程做深度体检。除逐文件语法检查（25 个 JS 全部通过）、引用完整性、图片/ID 完整性外，修复以下真实缺陷：

**数据安全类（严重）**
- **`moveNode` 防环失效（历史严重 bug）**：tree-utils 的防环检查依赖 `parent` 指针，但 `linkParents` 从未被调用——节点可被移动到自身子孙，子树从树中断开**彻底丢失**（已复现：`move b c` 后 b/c 消失，validate 不报错）。修复：改用 `pathTo` 判断目标是否在自身子树内（不依赖外部状态）。
- **schema 环检测失效**：递归 `validateNode` 遇环先栈溢出，环检测执行不到。修复：`validateProject` 在递归前先做迭代环检测；重复 id 检测同时修正（对象集合与 id 字符串混用导致失效）。
- **`parseArgs` 把 `--detail` 硬编码为 flag（历史严重 bug）**：`add/edit --detail "<值>"` 永远把 detail 设为 `true`，写盘校验必失败——**README 中的 `--detail` 示例一直不可用**。修复：移除显式 flag 行，通用分支兼容"带值"与"无值 flag"两种用法（read/get 的 `--detail` flag 用法不受影响）。

**功能缺失类**
- **UI 导出 Markdown 实际不可用**：`window.prompt` 在 Electron 渲染层不支持（返回 null）→ 导出静默失败。修复：改主进程 `dialog.showSaveDialog`（新增 `app:export-md-dialog` IPC）。

- **`add-image` 同毫秒重名覆盖**：文件名仅用 `Date.now()` → 连续添加可能互相覆盖。修复：追加随机后缀。

**工程化类**

- **测试覆盖严重不足**：仅 history 有单测（6 例）。新增 schema（5）/ tree-utils（7）/ markdown（8）/ convert（4）共 30 用例，覆盖环、防环移动、roundtrip 等。

### 修复启动乱码窗口（2026-09-15）

- **问题**：桌面「AI MindMap」快捷方式原指向 `启动AI MindMap.bat`——bat 文件为 UTF-8 编码，cmd 按 GBK 解码导致中文乱码、行解析错乱（`'锛?rem'`、`'ules'` 等报错），且 `start "" /b`+`exit` 会连带杀掉 electron 子进程。
- **修复**：改为 **VBS 隐藏窗口启动**（`启动AI MindMap.vbs`）：

  - 首次缺 electron 时才显示一个窗口跑 `npm install`（等完成），之后双击零黑窗直达应用；
  - 脚本取自身所在目录（`GetParentFolderName`），可随工程移动。
- 桌面快捷方式已改指向 vbs；旧 bat 已移除。
- **追加（同日）**：用户反馈 vbs 方案双击偶发无反应（疑似企业 EDR 对 wscript/vbs 的行为拦截）。最终方案：**桌面快捷方式直接指向 `node_modules\electron\dist\electron.exe` + 工程目录参数**（不经过 cmd/npx/vbs 任何脚本层，无拦截点、无黑窗、无乱码）。`启动AI MindMap.vbs` 保留在工程内作为备用（首次缺依赖时 npm install 兜底）。

### 修复「选中节点不显示详情」（2026-09-15）

- **根因**：所用 jsMind 0.9 版本**不派发 select 事件**（源码 `'select'` 分发次数为 0；`mousedown_handle` 点击节点只改选中样式），渲染层依赖 `add_event_listener('select')` 刷新详情面板 → 事件永远收不到，**所有项目选中节点都不显示详情**（此前冒烟断言手动调 `showDetail` 掩盖了该缺陷）。
- **修复**：`renderMind` 内 DOM 层监听容器 `click`，命中 `jmnode` 元素时 `select_node(id)` + `showDetail(node)`，补全「点击→选中→详情刷新」链路。
- **冒烟断言强化**：原 `image-node select` 改为 `click node → detail shows`——**模拟真实鼠标点击**（不再手动调 showDetail），验证详情面板更新；`detail images` 改为轮询等待图片异步加载（naturalWidth>0）。

### 本地 Git 仓库尝试结论（2026-09-15 晚）

- **尝试结果**：`git init` 成功（Git 2.55.0.3，`C:\Program Files\Git`），但 `git add` / `git hash-object -w` 写 `.git/objects` 均报 `Permission denied`；手动 PowerShell 写同一路径正常；`.git` 目录内出现探针符号链接（`tyawWZT → {testing}`）。系统安全软件为**亚信安全防毒墙（企业 EDR）+ Windows Defender**。
